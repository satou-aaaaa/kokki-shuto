# 国旗と首都

国旗か首都を手がかりに、どこの国かを4つから選ぶ1日5問のゲーム。前もって知らなくても、遊ぶうちに世界の国の国旗・首都・正式な国名を覚えられます。時間制限なし。

- 遊ぶ: https://satou-aaaaa.github.io/kokki-shuto/
- 今日の5問（ちがう地域の5か国。国旗から3問・首都から2問）はだれでも同じで1日1回。上級（むずかしい3問・手がかり2つから）、練習（地域を選んで何度でも・まだ当てていない国から）、とことん（全193か国）。
- 手がかりは3つまで（国旗か首都・正式な国名の伏せ字・首都か国旗）。少ない手がかりで当てるほど★が多くなります。まちがえても選び直せます。
- 当てた国は「国旗帳」に書きとめられ、国旗・首都・正式な国名を読み返せます。
- 見やすさの設定（読みやすい文字・色の見分け・動きを減らす・読み上げ）と、記録を別の端末へ移す「引き継ぎ」があります。

## 出典

- 国名・首都名・地域：外務省 キッズ外務省「[国名・首都名一覧](https://www.mofa.go.jp/mofaj/kids/ichiran/basic.html)」（2026年11月7日に読んだもの。写しは `tools/countries.tsv`）
- 国旗の絵：[flag-icons](https://github.com/lipis/flag-icons) 7.6.0（MIT ライセンス。`flags/LICENSE`）

一覧の196か国のうち、首都の欄が空のバチカンと、一覧で国名・首都に注の付いたアフガニスタン・イスラエルは出していません。地域は外務省の分け方のままで、北米は中南米と合わせて「南北アメリカ」にしています。まちがいに気づいたら、感想のフォームで教えてください。

## 記録と通信

記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を読み込むとき、まだ端末に保存が無ければ Google に IP アドレスが届きます。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（国の名前は入りません）。

## 開発

```bash
bash scripts/setup.sh   # 最初に一度
node qa/run.mjs         # 検査（CI と同じ）
```

国の表は `tools/countries.tsv` から `node tools/make-data.cjs` で作ります（決まりは AGENTS.md）。
